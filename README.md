# Shane Conversation Builder

A simple browser-based conversation practice tool for Shane.

It supports:

- Real-life conversation scenarios
- Answer choices with different support levels
- Ask-back practice
- Repair phrases for when a conversation is confusing
- Short 3-turn conversation practice
- Parent-created custom prompts
- Local session logs saved in the browser
- Browser read-aloud and microphone input when available

This is a home practice aid and is not a replacement for guidance from a licensed speech-language pathologist.

## Use

Open `index.html` in Chrome, or publish this repository with GitHub Pages.
